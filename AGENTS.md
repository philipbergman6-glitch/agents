Whale Panel: deterministic investor-persona diagnosis engine plus Claude Code subagents that narrate it. Three whales (Buffett, Graham, Lynch) each score a company from the same pinned SEC EDGAR snapshot under a versioned rubric; `/panel` fans all three out in parallel and reports agreement and disagreement without ever averaging them; `/portfolio` sanity-checks a client-chosen basket (equal weights, pairwise correlation, sector concentration) and renders no verdict. The engine is a uv-managed Python package in `whale_engine/` — run its CLI from that directory: `uv run whale fetch TICKER` (networked; needs `EDGAR_IDENTITY`), `uv run whale diagnose TICKER --whale buffett|graham|lynch` (offline, byte-identical for the same snapshot). Price history for the portfolio layer is a separate networked command — `uv run whale prices TICKER…` pins Alpha Vantage weekly adjusted closes to `snapshots/prices/` and needs `ALPHAVANTAGE_API_KEY` set (free key; never echoed). `uv run whale portfolio TICKER…` then reads those pinned price snapshots plus the EDGAR ones — offline and deterministic — and emits the equal-weight basket report under `portfolio_methodology_version`; changing that methodology needs a signed review, like a rubric. A name too young for a full fundamentals snapshot (a recent IPO fails `fetch` on the 10-TTM-window rule) gets its sector from `uv run whale fetch TICKER --sector-only`, which pins the SIC code alone to `snapshots/sectors/` — not a snapshot, unscorable by any whale, portfolio-layer only. `uv run whale fetch-13f` / `uv run whale holdings TICKER` cover the 13F whale-holdings roster. Tests: `cd whale_engine && uv run pytest`.

Internally the package is `whale_engine`: shared fetch/snapshot/CLI plus per-investor rubrics in `src/whale_engine/scorers/` (snapshots are whale-agnostic raw data — fetch once, any scorer diagnoses from the same file). `uv run buffett …` is a Buffett-pinned alias of the generic CLI. Rubric changes are versioned, never silent: every diagnosis carries `rubric_version`, and bumping it requires a signed judgment review (rubric v2 set this precedent when it replaced the original freeze). Persona prompts in `.claude/agents/` carry a `PROMPT_VERSION` for the same reason.

To diagnose a company, delegate to the `buffett`, `graham` or `lynch` subagent (`.claude/agents/*.md`) or the matching `/buffett`, `/graham`, `/lynch`, `/panel` skill; for a basket, the `portfolio` subagent or `/portfolio`. Never compute or estimate financial numbers yourself; every number must come from the engine.
