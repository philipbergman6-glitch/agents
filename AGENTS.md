Development repo for the Buffett company-diagnosis agent (deterministic scoring engine + Claude Code subagent). The engine is a uv-managed Python package in `whale_engine/` — run its CLI from that directory (`uv run buffett fetch|diagnose TICKER`; fetch needs `EDGAR_IDENTITY` set). Price history for the portfolio layer is a separate networked command — `uv run whale prices TICKER…` pins Alpha Vantage weekly adjusted closes to `snapshots/prices/` and needs `ALPHAVANTAGE_API_KEY` set (free key; never echoed). `uv run whale portfolio TICKER…` then reads those pinned price snapshots plus the EDGAR ones — offline and deterministic — and emits the equal-weight basket report (pairwise correlation, sector concentration, residual-risk caveat) under `portfolio_methodology_version`; changing that methodology needs an owner-signed review, like a rubric. Tests: `cd whale_engine && uv run pytest`.

Internally the package is `whale_engine`: shared fetch/snapshot/CLI plus per-investor rubrics in `src/whale_engine/scorers/` (snapshots are whale-agnostic raw data — fetch once, any scorer diagnoses from the same file). The generic CLI is `uv run whale diagnose TICKER --whale NAME`; `uv run buffett …` is the Buffett-pinned equivalent. Buffett rubric changes are versioned, never silent: every diagnosis carries `rubric_version`, and bumping it requires an owner-signed judgment review (ticket #40 set this precedent when it replaced the original freeze).

To diagnose a company, delegate to the `buffett` subagent (`.claude/agents/buffett.md`) or the `/buffett TICKER` skill — never compute or estimate financial numbers yourself; every number must come from the engine.
